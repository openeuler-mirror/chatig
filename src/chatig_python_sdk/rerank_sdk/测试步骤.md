### 步骤 2: 标准重排序测试

#### 2.1 基本重排序功能

```python
from rerank_client import RerankClient

client = RerankClient()

# 测试数据
documents = [
    "敏捷的棕色狐狸跳过懒狗。",
    "一只懒狗在阳光下睡觉。",
    "狐狸敏捷且棕色。",
    "狗是忠诚的伙伴。"
]
query = "敏捷狐狸"

try:
    response = client.rerank_std(
        model="bge-reranker-v2-m3",
        query=query,
        documents=documents,
        top_n=2
    )
    
    print(f"查询: {query}")
    print("结果:")
    for i, result in enumerate(response.results):
        print(f"  {i+1}. 分数: {result.score:.4f}, 文档: {documents[result.index]}")
        
except Exception as e:
    print(f"错误: {e}")
finally:
    client.close()
```

预期输出：
```
查询: 敏捷狐狸
结果:
  1. 分数: 0.8234, 文档: 敏捷的棕色狐狸跳过懒狗。
  2. 分数: 0.7123, 文档: 狐狸敏捷且棕色。
```

## 故障排除

### 常见问题

1. **连接错误**
   - 确保 Chatig 服务正在运行
   - 检查端口 8001 是否可访问
   - 验证防火墙设置

2. **模型未找到错误**
   - 确保指定的模型已在 Chatig 中配置
   - 检查模型名称是否正确

3. **超时错误**
   - 增加超时时间配置
   - 检查网络连接
   - 验证服务器性能

4. **认证错误**
   - 检查 API 密钥配置
   - 验证用户权限

### 调试技巧

1. **启用详细日志**

## 性能测试

对于性能测试，可以使用以下脚本：

```python
import time
from rerank_client import RerankClient

client = RerankClient()

documents = ["测试文档 " + str(i) for i in range(100)]
query = "测试查询"

start_time = time.time()
response = client.rerank_std(
    model="bge-reranker-v2-m3",
    query=query,
    documents=documents
)
end_time = time.time()

print(f"处理时间: {end_time - start_time:.2f} 秒")
print(f"文档数量: {len(documents)}")
print(f"平均处理时间: {(end_time - start_time) / len(documents) * 1000:.2f} 毫秒/文档")

client.close()
```
